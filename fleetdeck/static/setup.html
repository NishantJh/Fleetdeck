Enter the setup code

Only someone who can see this server's logs can set it up, so nobody else on your network can claim the admin login. The code is in a log line like Setup code: ... and changes every time the container starts.

  • Portainer, Dockge, Arcane, Komodo, ...: open the fleetdeck container's logs.
  • A shell on the Docker host: docker logs fleetdeck 2>&1 | grep "Setup code"

1. Create the admin login

This login protects the dashboard. It can run commands as root on every machine you add, so use a strong password.

Or restore from a backup a .hlmbackup file from the dashboard's Backup button

Brings back the login, the machines, the dashboard's keys and the job history, so the machines don't need their scripts run again.

Connection security

The address(es) machines see the dashboard connect from: this Docker host's LAN IP, and your home's public IP for a VPS. Leave empty to allow any. Changing it changes the scripts.

Connections

For each machine: fill in its details, run the script it shows on that machine (in any shell, as root or as a user who can use sudo, doas or su), then press Connect. The dashboard does the rest over SSH.

Apply

Changes are saved. Apply them to start using them on the dashboard.
