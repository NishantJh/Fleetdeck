Homelab Manager setup

Dashboard

1. Create the admin login

This login protects the dashboard. It can run commands as root on every machine you add, so use a strong password.

Machines

For each machine: fill in its details, run the script it shows on that machine (in any shell, as root or as a user who can use sudo, doas or su), then press Connect. The dashboard does the rest over SSH.

Apply

Changes are saved. Apply them to start using them on the dashboard.

Edit config.yaml (schedule, notifications, protected guests, everything else)

Checked before it's saved. See config.example.yaml in the repository for every setting.
